## MVP Learning Loop

### MVP Goal

Describe the smallest product slice that lets the developer see or try the core experience quickly.

### Core Assumption To Validate

State the most important product, workflow, technical, or adoption assumption that this MVP should test.

### Fastest Observable Outcome

Describe the concrete effect the developer can see, run, click through, or inspect after the next slice ships.

### Feedback Questions

After this MVP, the developer should be able to answer:

- Is the core direction still right?
- Does the first usage path make sense?
- Which candidate should move earlier or later?
- Should any candidate be split, removed, or reframed?
