### D001: 技术选型示例

**日期**: 2026-01-01
**状态**: 🟢 已采纳 / 🟡 待定 / 🔴 已废弃
**决策者**: 项目团队

**背景**:
说明为什么需要做这个决策，以及当前面临的问题。

**选项**:
1. **选项 A**: 第一种可行方案
   - 优点: 说明优势
   - 缺点: 说明代价
   - 成本: 低 / 中 / 高

2. **选项 B**: 第二种可行方案
   - 优点: 说明优势
   - 缺点: 说明代价
   - 成本: 低 / 中 / 高

**决策**:
说明选择了哪个选项，以及为什么。

**后果**:
- 正面影响: 说明收益
- 负面影响: 说明约束
- 技术债务: 说明后续需要偿还的工作；没有则写“无”

**验证**:
- 验证标准 1
- 验证标准 2
